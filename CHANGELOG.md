# Changelog

## 1.0.0 — Oracle public export

- Published the complete oracle recompilation sources for `MW4Mercs.exe` and
  the six code-bearing game DLLs.
- Added the reference-free image assembler workflow and per-function
  diff/no-mask verification tools.
- Added the public build guide, verification methodology, architecture notes,
  per-VA subsystem indexes, data annotation indexes, and module notes.
- Committed the reference-derived data sources and `.bin` artifacts so the
  default build and hash gate are self-contained.
- Excluded reference binaries, original game assets, and private build outputs.
