    Verification¶

    The acceptance criterion is byte identity with the canonical reference, not a similarity score. Three checks build up to it.

    1. Masked per-function diff¶

    nmake diff FUNC=0x00401000 OBJNAME=build\obj\func_00401000.obj

    tools/diff.py slices the reference function's bytes from the binary and compares them to the compiled object's .text section. Four-byte relocation sites are masked because an unlinked object still contains placeholder values there. This is a fast iteration tool, not the final gate.

    2. No-mask per-function check¶

    nmake nomask FUNC=0x00401000 OBJNAME=build\obj\func_00401000.obj

    tools/verify_nomask.py places the object at its reference VA, resolves every relocation from the symbol name and the committed src\<target>\artifacts\extern_addrs.csv table, and compares every byte. This catches misaligned or spurious relocation sites that the masked diff hides.

    3. Full-image assembly¶

    nmake exe
nmake dll-all MOD=gundll

    The assembler composes the complete binary from the compiled objects plus the generated data sections and metadata artifacts, then compares the result to the reference with no masking. This is the authoritative gate. It catches:

    • function ordering and overlap errors,
    • missing or wrong inter-function padding,
    • section composition errors,
    • unresolved or mis-resolved relocations,
    • data-section placement errors.

    A successful run prints:

    diff: byte-identical to reference (SHA-256 ...)

    or, for a module:

    == <module>: byte-identical to reference (no masking, reference-free build) ==

    Reproducibility notes¶

    • The PE timestamp/checksum/Rich header are pinned by the committed pe_headers.bin artifact, not by the current clock.
    • The build reads no reference content after nmake init; only --diff opens the reference.
    • Generated data sections and .bin artifacts are intentionally not committed. They are deterministic functions of the user's reference binary.
    • The build is not run in GitHub Actions: the pinned MSVC6 toolchain is not available on hosted runners. Verification is a local Windows gate.

    Known limitations¶

    • A user must supply the exact canonical reference version. A different build will fail the data/byte gates.
    • The per-function diff uses reference/functions/*.csv for sizes. Functions missing from that inventory can be checked with an explicit SIZE=....
    • gundll intentionally has out-of-scope .text ranges; its coverage report uses reference/in_scope/gundll.txt. The full-image diff is still the gate.
