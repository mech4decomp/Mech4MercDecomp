# Source layout

Sources are organized by binary target and PE section:

```
src/
  mw4mercs/
    text/        func_<VA>.c + in-.text data_<VA>.c
    artifacts/   committed CSV metadata
  blade/
  gundll/
  language/
  missionlang_mercs/
  mw4stats/
  zloglib/
```

- Filenames are canonical: `func_<8-hex-va>.c` / `data_<8-hex-va>.c`.
- Semantics live in the file header and comments, not the filename.
- Non-`.text` data runs are generated locally and are gitignored.
- `.bin` artifacts are generated by `nmake init` / `nmake dll-init`.

Other directories:

- `include/mw4/` — shared format headers.
- `tools/` — build, diff, annotation, optional RE tools.
- `docs/` — documentation and static indexes.
- `reference/` — hashes, function inventories, user-supplied binaries.

See
[`docs/ARCHITECTURE.md`](https://github.com/mech4decomp/Mech4MercDecomp/blob/main/docs/ARCHITECTURE.md).
