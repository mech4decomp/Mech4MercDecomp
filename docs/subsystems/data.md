## How it works

`.rdata` holds constants, vtables, and import tables; `.data` holds initialized state; `.rsrc` is the PE resource directory; `.txt2` is the SafeDisc leftover. In-.text data blocks are jump or pointer tables emitted as data placeholders.

In the public snapshot these data sources are generated locally from the user's reference and are not committed. The tables below list the VAs and the source path that would generate them.

## Key entry points

| VA | Detail | What it does |
|----|--------|--------------|
| 0x00770000-0x007AFFFF | rdata | constants/vtables/imports |
| 0x007B0000-0x008BFFFF | data | initialized game state |
| 0x00769000-0x0076AFFF | txt2 | SafeDisc .txt2 section |
