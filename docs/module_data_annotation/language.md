# Language.dll data annotation index

Byte-exact data runs (`src/language/<section>/data_0x*.c`) with inline
semantic annotations. Generated by `tools/module_annotate_data.py`.
IAT = import address table, ILT = import lookup table,
IMPD = import descriptor, EXPORT = export directory, vtable = method run.

> The data sources themselves are committed, so the default build is
> reference-free. `nmake data` remains the optional regeneration path.
> See `docs/BUILD.md`.
