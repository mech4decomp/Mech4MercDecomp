# Agent / contributor guide — oracle track only

## Scope

This repository is the **byte-identical oracle track**. The sources are
complete and frozen. Do not modify `src/`, `include/`, or the build tooling to
change behavior. Documentation corrections are welcome.

The fork/mod/clean-reimplementation work is intentionally **not** part of this
repository. Do not add hook code, fork design docs, or source-reconstruction
work here.

## Build order

```bat
call tools\env.bat
nmake objs      :: compile .text sources
nmake data      :: generate/compile non-.text data from the user's reference
nmake init      :: extract metadata artifacts (needs objs)
nmake exe       :: assemble + byte-diff
```

Modules: `nmake dll-all MOD=gundll` (and the other module keys). The `init`
step must run after `objs` because the residual extern table is learned from the
compiled objects.

## Layout

- `src/<target>/text/` — `func_<VA>.c` and in-`.text` `data_<VA>.c`
- `src/<target>/artifacts/` — committed CSV metadata only; `.bin` artifacts
  are generated by `nmake init` / `nmake dll-init`
- `include/mw4/` — shared format headers
- `tools/` — build, diff, annotation, and optional RE utilities
- `docs/` — public documentation and static indexes
- `reference/` — hashes and metadata; user-supplied binaries are ignored

Generated data sections (`src/*/rdata`, `src/*/data`, `src/*/rsrc`,
`src/*/txt2`) are gitignored and must not be committed.

## Verification

- `nmake verify` — hash gate for all built images.
- `nmake diff FUNC=... OBJNAME=...` — masked per-function diff.
- `nmake nomask FUNC=... OBJNAME=...` — full no-mask check.
- `python tools/audit_public_export.py` — public-repo policy audit.

## Rules

- Never commit reference binaries, generated data sections, or `.bin`
  artifacts.
- Never add personal information, tokens, or absolute local paths.
- Keep docs factual and evidence-based (binary, VA, section, hash).
- Do not add fork/mod code or fork-specific design documents.
- Do not change oracle sources without maintainer approval and a byte gate.
